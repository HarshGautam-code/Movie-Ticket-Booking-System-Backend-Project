# 🎟 Movie Ticket Booking System

## 📌 Description
The Movie Ticket Booking System is a full-stack web application that allows users to browse available movies, check show timings, select seats, and book tickets online. Theater owners can register on the platform and add their own movie shows. Movie owners get access to a dashboard where they can monitor all movies, including tickets sold and user ratings.

After a successful booking, users receive a confirmation email along with their ticket details.

This system provides a complete end-to-end movie booking and management experience for both customers and movie/theater owners.

---

## 🚀 Features

### 👤 User Features
- View list of available movies
- Check show timings
- Visual seat selection
- Book tickets online
- Receive booking confirmation via email
- Get ticket details on registered email

### 🎬 Theater Owner Features
- Register as theater owner
- Add new movie shows
- Manage show details
- Publish shows for booking

### 📊 Movie Owner Dashboard
- View dashboard of listed movies
- Track total tickets sold
- Monitor movie ratings and feedback
- Analyze performance of shows
- Manage movie availability

## ⚙️ How It Works
1. Users browse movies and available shows.
2. Users select preferred seats.
3. Booking is processed and stored in the database.
4. Confirmation email is sent automatically.
5. Theater owners manage and publish shows.
6. Movie owners track performance via dashboard analytics.

---

## 📧 Email Notification
After successful booking:
- Confirmation message is sent
- Ticket details are delivered via email
